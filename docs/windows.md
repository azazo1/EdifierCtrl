# Windows 桌面应用

WinUI 3 客户端使用与 macOS 相同的页面结构, 通过 Rust C ABI 控制耳机和跨设备交接.

## 构建与运行

需要 Windows, Rust MSVC 工具链, 支持 .NET 8 目标的 SDK, PowerShell 7 和 just. 项目使用自包含 Windows App SDK.

```shell
just windows build
just windows run
just windows debug
just windows dist
```

`debug` 使用 `target/edifierctrl-windows-debug/` 独立保存设置和日志, 默认 trace 级别. `dist` 生成自包含 Windows x64 目录与 ZIP, 位于 `target/windows/dist/`. 构建可通过 `APP_VERSION` 注入显示版本, 未指定时显示 `dev-build`. Release 不弹出控制台, Debug 保留终端日志与 Ctrl+C 退出.

## 页面与操作

- 我的耳机: 显示连接, 电量和固件读数, 按机型能力显示聆听模式, 播放, 音效和高级设置. 未回报的数据保留未知状态. 设置发送成功后等待耳机回报, 不把发送结果当作已生效.
- 设备连接: 扫描已配对耳机, 连接上次设备或手动输入蓝牙地址. 被其他组成员占用的耳机可发起接管. 默认使用经典蓝牙, BLE 放在高级连接选项中.
- 跨设备交接: 使用普通文本组名加入同一局域网的交接组, 展示成员和当前持有的耳机, 显示释放与连接进度. 接管成功以核心确认的系统音频状态为准.
- 应用设置: 启动隐藏, 自动入组, 详细日志和跟随系统的明暗主题.
- 活动记录: 保留本次运行最近 200 条活动, 协议编码与解析位于折叠诊断区. 设备维护及原始指令发送需要确认.

请先在 Windows 蓝牙设置中完成配对. 控制通道与系统音频分别显示, 断开控制不等于释放音频. 各设备使用完全相同的组名, 并允许本地网络通信. 组名可记住或在退出后不保存.

## 后台行为

关闭主窗口会隐藏到托盘并保留耳机服务. 托盘左键显示并聚焦原窗口, 右键菜单提供交接, 设置和退出. 托盘不可用时保持窗口可见, 关闭窗口直接退出, 避免出现无法唤回的后台进程.

同一数据目录只运行一个实例, 再次启动会唤起已有窗口. 仅记忆普通窗口尺寸与最大化状态, 不保存屏幕位置. 托盘退出, 设置页退出和终端 Ctrl+C 汇入同一收尾过程, 停止轮询并等待原生调用完成后释放会话.

默认数据目录为 `%LOCALAPPDATA%/EdifierCtrl/`. `EDIFIER_DATA_DIR` 和 `EDIFIER_LOG_FILE` 可分别覆盖数据与日志位置. 设置使用带格式版本的 JSON 保存, Rust 核心 tracing 日志并入应用日志, 按日期和 5 MiB 大小轮转, 保留 10 个归档. 未捕获异常和 Rust panic 会记录并刷盘.

版本入口展示应用与核心版本, 并提供 GitHub 发行页链接. 当前 Windows 版本不包含自动下载和替换更新.
